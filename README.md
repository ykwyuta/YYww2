# 鋼鉄の大地 / YYww2

第二次世界大戦の戦車で戦うリアルタイムストラテジー。2つの陣営が同じ予算で戦車を調達・配置し、相手の基地を占領するか、相手の戦車をすべて撃破したほうが勝つ。

YYMythology と同じく Rust で書いており、ブラウザ版（WebAssembly）と Windows 版（Direct3D11 / Direct2D）がある。

## 遊び方

1. **タイトル画面**で戦場・予算規模・敵の強さを選ぶ。
2. **準備フェーズ**：予算の範囲で戦車を買い、自陣に配置する。開戦前にだけ、デコイと竜の歯を置ける。
3. **戦闘フェーズ**：戦車を指揮して戦う。デコイや竜の歯は追加できない。
4. 敵の基地を占領するか、敵の戦車をすべて撃破すれば勝ち。15分で決着しなければ、残った戦力（調達額×残り耐久）で判定する。

### 将軍

全将軍が固有スキルを持ちます。将軍パネルで効果・発動状態を確認でき、1戦1回のスキルは戦闘中に「固有スキル発動」で使用します。[全将軍のスキル一覧](GENERAL_SKILLS.md)も参照してください。

準備画面の「将軍」で、将軍を選んでから配置済みの戦車をクリックする。ドラッグで複数の戦車にまとめて委任でき、タッチ端末では戦車をタップして指定できる。「直轄へ戻す」を選んで同じ操作をすると委任を解除できる。

開戦後、委任された戦車は将軍が自動で動かす。戦略は積極攻勢、ゲリラ抵抗、拠点防衛、遊撃の4種類で、将軍ごとに決まっている。Qキーでは直轄の戦車をすべて選択する。

戦闘中に「将軍 G」から指揮している将軍を選んで「指揮権を返還」すると、委任していた戦車が直轄に戻り、その将軍は「副官」となる。副官は選択中の戦車の「委任」ボタンや「将軍 G」パネルから再び戦車の指揮を任せられる。

将軍の通信は戦闘画面の右下に表示される。前進や待機などの命令と戦況報告が届き、委任部隊が苦戦すると将軍が総司令官に救援を求める。「現場へ」で要請地点にカメラを移せる。

視認した敵将軍の部隊からの発言は「敵軍通信」として表示される。

### 戦場

史実の戦車戦の舞台をもとにした、性格の異なる6つの戦場から選ぶ。地形は毎回生成され、双方に公平になるよう左右対称になる。

| 戦場 | 特徴 |
| --- | --- |
| クルスク（プロホロフカ） | 開けた草原と丘、村、北の川。長射程の重戦車が活きる |
| アルデンヌの森 | 深い森と細い道、中央の川。森は視界を遮り重戦車は鈍る |
| アルプス山岳 | 通れない山岳。谷と峠道の争い |
| エル・アラメイン | 遮蔽物の少ない砂漠と尾根、南の塩湿地、北の海岸道路 |
| ノルマンディーのボカージュ | 生垣で区切られた畑。視界が短く待ち伏せ向き |
| スターリングラード市街 | 瓦礫の市街地と大通り。近距離戦 |

### 予算規模

小（3000）・中（6000）・大（11000）。双方が同じ予算で準備する。

### 戦車

国は選ばない。ドイツ・ソ連・アメリカ・イギリス・日本・イタリアの全42車種（各国のマイナー戦車・試作重戦車・自走砲を含む）から自由に組み合わせて買える。

- ドイツ・ソ連の強力な戦車（ティーガーI 820、IS-2 780、パンター 650 など）は調達コストが高い。
- 日本・イタリアの戦車（ハ号 65、L6/40 60、チハ 105 など）は安く、数と速さで勝負できる。
- 装甲は正面・側面・背面で異なる。側面や背面を撃てば、軽戦車でも重戦車を撃ち抜ける。
- 移動しながらの射撃は命中率が下がる。

### 地形

森・湿地・丘・村落・浅瀬・生垣・砂地では進撃が遅くなる。重い戦車ほど悪路で遅い。川と山岳は通れず、橋と浅瀬を渡る。
森・村落・生垣の中の戦車は近づかないと見つからない（撃つと位置がばれる）。丘の上からは遠くまで見える。

### デコイ・竜の歯・偵察ドローン

- **デコイ**（30）：好きな戦車に偽装した張りぼて。敵には本物に見え、攻撃を引きつける。敵の戦車が近づくと見破られる。
- **竜の歯**（20）：対戦車障害物。戦車は通れず、敵は砲撃して壊さなければならない。ドラッグで連続して置ける。
- **偵察ドローン**：双方1機ずつ、開戦時に基地から飛び立つ。地形を無視して飛び、視界を広げる。戦力には数えず、攻撃対象にもならない。自軍のドローンを選んで「自動巡回」を押すと、前線と敵陣を順に偵察する。Pキーでも切り替えられ、手動の移動・停止で解除できる。

デコイと竜の歯は自陣側の中央手前まで、戦車は基地側の配置範囲にだけ置ける。

### 操作

| 操作 | 内容 |
| --- | --- |
| 左クリック／ドラッグ | 選択・範囲選択（準備中は配置） |
| 右クリック | 移動、敵を指すと攻撃（準備中は撤去） |
| A → 地点 | 攻撃移動（敵を見つけたら止まって撃つ） |
| S / Q / D | 停止 / 全戦車を選ぶ / ドローンを選ぶ |
| Space、＋／－ | 一時停止、速度 |
| 矢印キー・画面端・中ボタンドラッグ・ホイール | 地図の移動と拡大縮小 |
| F1 または H | 操作と規則 |

スマートフォン・タブレットでは横向きで遊ぶ。タップで選択と命令、なぞって地図の移動、長押ししてなぞると範囲選択、ピンチで拡大縮小。

## 起動

Windows 版

```powershell
cargo run --release --locked --bin yyww2-win
```

ブラウザ版

```sh
bash build.sh
python -m http.server 8000 --directory dist
```

ビルド後に [ローカルのゲーム画面](http://localhost:8000/) を開く。

テスト

```sh
cargo test --release --lib
```

## Cloudflare への公開

YYMythology と同じ構成で、Workers Static Assets または Pages に `dist/` を配信する。

- **Workers** は `npm run deploy`。公開先の Worker 名は `yyww2`。
- **Pages** はビルドコマンドを `npm run build`（または `bash build.sh`）、出力ディレクトリを `dist` に設定する。

ビルド時に、配信ファイルが Cloudflare の1ファイル 25 MiB 制限に収まるかを確認する。

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/data.rs` | 国・戦車の諸元、地形の性質、予算規模 |
| `src/map.rs` | 戦場の生成（左右対称）、経路探索、視線、地形の絵 |
| `src/sim.rs` | 準備と戦闘のシミュレーション（射撃と装甲、視界、デコイ、竜の歯、ドローン、占領、勝敗） |
| `src/ai.rs` | コンピュータ陣営の準備と指揮 |
| `src/game.rs` | 画面・操作・描画 |
| `src/gfx.rs`, `src/web.rs`, `web/` | ブラウザ版の描画（WebGL2 / Canvas2D）と入力 |
| `src/win/` | Windows 版の描画（Direct3D11 / Direct2D / DirectWrite）とウィンドウ |

描画・入力・Windows 版の層は YYMythology から引き継いだ。アイコンと読み込み画面の絵は `python tools/make_brand.py`、真上視点スプライトアトラスは `python tools/make_topdown_sprites.py`、透過RGBAスプライトは `python tools/make_sprites.py`（いずれも Pillow が必要）で再生成できる。
